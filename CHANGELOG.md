## Unreleased — 0.2.0 development

- Standardized all three web workspaces, default lesson content, accessibility labels and validation messages on English. Imported/user-authored content is preserved.

- Local Evaluation Inspector: validated binary JSON import, confusion metrics, filtered cases and evidence JSON with declared provenance, content hash and reviewer notes. No inference or assurance score.
- Evidence-centered assurance plan and revised Arsenal proposal draft; Inspector included in the English publication update.

- Learning demo at `/learn/`: two worlds, identical messages, prediction/reveal, constrained lesson authoring and JSON exchange.
- Beginner explanations, purple remembered-position pin and a separate fixed offset illustration.

- Focused A/A′/R/B comparison, isolated receiver-only mode, on-marker data age and story-specific distance measurements; original panes available on demand.
- Guided three-stop entry, nearby evidence and playback, collapsible advanced controls, and downloadable reproduction instructions.
- One-way V2V flow and collapsible send/omit/receive log derived from the existing schedule. No model or export-schema change.
- Oblique/top-down camera selection and optional position histories.
- Bilingual sample/line legend distinguishing truth, claims and the receiver.
- Receiver trails and camera framing use arrived claims only, unless the explicit
  teaching overlay is enabled. Camera memory resets on rewind or visibility changes.
- Display-data regression tests and browser checks; report schemas unchanged.

The application identifies this work as `0.2.0-dev`; no v0.2.0 release is published.

## 0.1.0 — 2026-10-11

Initial MVP for exploring receiver observation limits in synthetic
constant-position-offset messages.

- Three guided presets, bilingual UI, sender/receiver message-pair comparisons.
- Offset interval and boundary navigation; ground truth optional in receiver view.
- Synchronized smooth camera transitions, zoom, expanded views and labeled rings.
- Validated scenario import/export and full synthetic trace export.
- Deterministic JSON reproduction reports and readable Markdown summaries.
- Source-only offline use, MIT license and community/security reporting guidance.

This version is a prerelease MVP. The full browser/device matrix is not certified.
No RF, real-vehicle, detector-performance or safety claims are made.
