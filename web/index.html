Spoken narration

  1. Two worlds. Identical messages. Can receiver B tell which world reports the wrong position? Look only at the information B receives.
  2. Now reveal the true positions. In world two, the claim is eight meters ahead of the car. Yet B receives the same messages.
  3. Both cars move three meters each second. Matching position changes do not prove that the reported position is correct. B needs independent evidence.
  4. Try V two X Observation Lab. Create a lesson, reveal the evidence, and share the scenario. Synthetic examples, not a detector or safety verdict.

One message per simulated second, immediate delivery, fixed +8 m offset in world 2. Animation time is slowed for explanation; the movement is interpolated between model samples. Receiver readouts update only at those samples. The final five-second model state is held. No real radio traffic, detector bypass or safety outcome is demonstrated.

Numbers and formulas (optional)

Delta means change between two transmissions here. Δp is the true position change; Δp′ is the reported change. (3, 0) m means +3 metres along X and no change along Y, not the car’s current coordinates. demo-21 is just a message ID. R is the technical name for the “B remembers” pin.

Interpretation limits

Equal differences do not prove position correctness. The receiver lacks ground truth to compute Δp; checking position correctness requires an independent reference.

Formulas, assumptions and limitations

A(t) = (−30 + 3t, 0) m; B(t) = (0, −20 + 2t) m. p′(t) = p(t) + c when start ≤ t < end; c = (dx, dy).

One message per second; fixed delay and user-selected periodic omissions. No RF, GNSS, certificates, vehicle dimensions, collisions or driver response are simulated. Crossing point trajectories do not establish a crash. A constant offset cancels in differences only within a segment with that same offset. Values and vehicle labels are authored from formulas, not measured traces.

Applying a configuration resets time. Exports use the applied configuration, not pending edits. Imported files are read in your browser and are not uploaded.
